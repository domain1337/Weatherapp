# Weatherapp

Android-приложение с текущей погодой и прогнозом по часам и дням. Можно сохранить города с заметками и переключаться между ними. Прогноз загружается из [OpenWeather 5 day / 3 hour forecast](https://openweathermap.org/forecast5), список городов хранится локально через Room.

## Запуск

1. Установите Android Studio с Android SDK 36 и JDK 17. Откройте корневую папку проекта.
2. Создайте собственный ключ OpenWeather. Передайте его через переменную окружения `WEATHER_API_KEY` или параметр Gradle `-PWEATHER_API_KEY=ваш_ключ`. Например, в PowerShell для текущего терминала:

   ```powershell
   $env:WEATHER_API_KEY = "ваш_ключ"
   .\gradlew.bat :app:assembleDebug
   ```

3. Запустите приложение на устройстве или эмуляторе с Android 7.0 (API 24) или новее. Сборка без ключа возможна, но приложение покажет инструкцию вместо прогноза.

Ключ не хранится в репозитории. Не записывайте его в отслеживаемые файлы. Как и любой ключ, встроенный в мобильное приложение при сборке, он может быть извлечён из APK; ограничьте его использование в кабинете OpenWeather. **Ключ из прежней версии исходников уже был публичным: отзовите его и выпустите новый в кабинете OpenWeather.** Удаление строки из текущих файлов не удаляет её из опубликованной истории Git и уже выпущенных APK.

## Использование

На главном экране показана погода для Москвы. Кнопка справа сверху открывает список сохранённых городов. Кнопка `+` позволяет добавить город и необязательную заметку; выбор города открывает его прогноз. Если город не найден либо есть ошибка сети или API, приложение показывает сообщение вместо устаревших данных.

## Проверка

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

Для проверки вручную попробуйте существующий и несуществующий город, затем отключите интернет. С неверным ключом API должно появиться сообщение об ошибке ключа.
